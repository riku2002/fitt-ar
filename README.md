# Realtime AR Try-On

カメラに映る人の姿勢を推定し、3Dの服を身体に重ねて試着するWebアプリです。トップスとボトムスを組み合わせたり、ワンピースを選んだりできます。

公開サイト: [fitt-ar.vercel.app](https://fitt-ar.vercel.app)

## 主な機能

- MediaPipe Pose Landmarker Liteで1人の身体と手首を追跡します。GPUを優先し、使えない場合はCPUで動作します。
- Three.jsでGLB形式の服を描画します。肩や腰を基準に位置・大きさ・向きを合わせ、検出が途切れると服を非表示にします。
- トップスとボトムスを同時に着用できます。ワンピースの着用中はボトムスを一時的に隠します。
- 「男性」「女性」「全て」で候補を絞り込めます。共用の服は男性・女性の両方に表示されます。絞り込みや操作対象を変えても、着用中の服は維持されます。
- サムネイル、前／次ボタン、手のジェスチャーで服を選べます。服・骨格の表示と鏡表示は個別に切り替えられます。

映像と姿勢座標はブラウザ内で処理します。録画・保存・サーバー送信・マイク取得は行いません。推定モデル、WASM、服の3Dモデルはアプリと同じ配信元から読み込みます。

## 起動方法

Node.js **24.x** とnpmを用意します。カメラで試す場合はChromeなどの対応ブラウザとカメラが必要です。

```bash
git clone https://github.com/riku2002/fitt-ar.git
cd fitt-ar
npm ci
npm run dev
```

表示されたURL（通常は `http://localhost:5173/`）を開き、**カメラを起動**を押してアクセスを許可してください。APIキーや環境変数の設定は不要です。`npm run dev` と `npm run build` の前処理で、推定モデルのハッシュを検証し、対応するWASMを配置します。

カメラは `localhost` またはHTTPSで使用してください。スマートフォンからLAN内の通常のHTTPアドレスに接続しても、ブラウザがカメラ利用を許可しない場合があります。

## 試着と操作

1. 正面を向き、肩から腰までが見える範囲に立ちます。ボトムスを試すときは脚も映してください。
2. **トップス／ボトムス**のタブで操作対象を選び、サムネイルまたは**前の服／次の服**で服を選びます。トップスの一覧にはワンピースも含まれます。
3. 必要に応じて**商品の絞り込み**を切り替えます。選択中の服は維持され、候補だけが変わります。
4. **着用中**の一覧から服を外せます。ワンピースを選ぶと、選択済みのボトムスは記憶したまま一時的に隠れます。通常のトップスに戻すと再表示されます。

起動時は最初のトップスが選択され、ボトムスは未選択です。服の描画をOFFにするとジェスチャー操作も無効になります。骨格表示は初期OFFです。

### 手のジェスチャー

- 片手を胸の高さで横へ動かすと、操作対象の服を切り替えます。**画面上で右から左は次、左から右は前**です。鏡表示を切り替えても画面上の方向は同じです。
- 両手首を肩より上に約0.7秒保つと、操作対象がトップスとボトムスの間で切り替わります。次の操作をする前に両手を肩より下へ戻してください。
- スワイプ後は約0.6秒の待機があります。手を少し止めるか下ろすと、次のスワイプを受け付けます。
- **手のジェスチャーで切り替え**をOFFにすると、ボタンとサムネイルだけで操作できます。画面を指でなぞるタッチ操作ではありません。

カメラ映像上にジェスチャーの進行状況や姿勢推定のメッセージは表示しません。反応しにくい場合は、肩と手首が映るように位置や明るさを調整してください。判定条件と検証記録は[スワイプ改善の検証記録](docs/swipe-reliability.md)を参照してください。

## 服のデータ

現行の試着画面は **GLB形式の3Dモデル**を使います。18点の服を同梱しており、モデルと選択画面用のアイコンは `public/garments/` にあります。服の一覧、性別区分、カテゴリ、モデルURL、サイズ調整は `src/features/wardrobe/garments.ts` に定義します。性別区分は商品を絞り込むためのもので、カメラから利用者の性別を推定する処理はありません。

新しい3Dモデルを追加・調整する際は、[服のアンカー設定](docs/garment-anchors.md)と[3D表示の検証手順](docs/3d-display-validation.md)を参照してください。`config/garment-anchors.json` にアンカー設定があります。モデルの圧縮については[服の切り替え性能](docs/garment-switch-performance.md)を参照してください。

`tshirt-gray.png` などの透過PNGと[写真からTシャツ素材を作る手順書](docs/garment-guide.md)、[位置合わせツール](public/tools/garment-setup.html)は、旧2D描画用の資料・ツールです。PNGやその4点アンカーを登録するだけでは、現在の3D試着画面に服は追加されません。

## 実装の概要

```text
カメラ映像 → Pose Landmarker → PoseFrame
                               ├─ GarmentOverlay（GLBの3D描画）
                               ├─ PoseOverlay（骨格表示、任意）
                               └─ SwipeGesture（服と操作対象の切り替え）
```

`VirtualMirror` が推定セッションを管理し、`PoseSource.subscribe()` で各機能に姿勢座標を配信します。服の選択や操作対象の変更では推定モデルを再生成しません。服と骨格の表示を両方OFFにすると推定を停止します。画面離脱やカメラ停止時にはストリームと推定処理を解放します。

開発環境では画面左下の **DEV INPUT** から同梱のテスト動画に切り替えられます。カメラなしで描画やジェスチャーを確認するための機能です。

## トラブルシューティング

- カメラが起動しない場合は、ブラウザとOSのカメラ権限を確認し、カメラを使っている他のアプリを閉じてください。権限拒否や切断の案内は設定パネルに表示されます。
- 服が表示されない場合は、肩や腰が映る位置で正面を向き、**服を表示**がONで、**着用中**に服があることを確認してください。ワンピース着用中はボトムスが隠れます。
- 姿勢推定や3Dモデルの読み込みに失敗した場合は、ページを再読み込みしてください。続く場合は、モデルファイルとブラウザの開発者ツールで読み込みエラーを確認してください。画面上に推定・モデルの再試行ボタンは表示していません。
- `EBADENGINE` が出た場合は `node -v` でNode.js 24.xを使用しているか確認してください。
- 公開時は `npm run build` で生成した `dist/` 全体を配信してください。`models/`、`mediapipe/wasm/`、`garments/` も必要です。

## 現在の制限

試着は見た目の位置合わせで、衣服の実寸やサイズ適合を判定するものではありません。姿勢推定はメインスレッドで実行するため、端末性能や明るさ、身体の遮蔽によって追跡・ジェスチャーの反応が変わります。カメラ映像には診断値や進行状況を重ねて表示しません。
