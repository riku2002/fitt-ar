FITT-AR / 素材づくりの補助ツール

写真に、4つの目印を。

透過PNGを選ぶ → 肩と腰をクリック → 設定をコピー。座標の計算は不要です。

選んだ写真はこのブラウザ内だけで処理します。サーバーへのアップロードや保存は行いません。背景の切り抜きは、事前に画像編集ソフトで行ってください。

1. 透過PNGを選ぶ

背景を切り替え、白い四角や市松模様が画像に焼き込まれていないか確認します。

2. 肩・腰を4か所クリック

左右は着ている人から見た左右です。正面の写真では「左肩」は画像の右側になります。

肩は袖口ではなく肩の関節が入る位置。腰は裾ではなく股関節が入る高さを目安にします。点は仮の位置でよく、試着画面で微調整できます。

修正したい点のボタンを選び、画像をクリックし直してください。キーボードの場合は画像にフォーカスして矢印キー → Enter。Shift＋矢印で細かく動かせます。

3. 設定をコピーして追加

半角の小文字・数字・ハイフン＋.png。画像をこの名前で public/garments/ に置きます。このページからはファイルを書き換えません。

src/features/wardrobe/garments.ts の export const demoGarment: Garment = { … } 全体を置き換えます。上にある型定義は残してください。コピー後は変更を保存して試着画面を再読み込みします。
