# デモ用Tシャツ

`demo-tshirt-sage.png` は、このプロジェクトで図形から作成した800×800の透過PNGです。写真・第三者の商品画像・画像生成サービスは使用していません。身体追従の動作確認用で、実在の商品やサイズを表すものではありません。

再生成: `node scripts/generate-demo-garment.mjs`（Node.jsの標準機能のみ使用）。通常のセットアップでは再生成不要です。

アンカーは `src/features/wardrobe/garments.ts` で管理します。左右は**着用者から見た左右**です。正面向き画像では、着用者の左肩は画像右側になります。

| アンカー | 正規化座標 | 画像座標   |
| -------- | ---------- | ---------- |
| 左肩     | (0.7, 0.2) | (560, 160) |
| 右肩     | (0.3, 0.2) | (240, 160) |
| 左腰     | (0.7, 0.8) | (560, 640) |
| 右腰     | (0.3, 0.8) | (240, 640) |

画像を差し替える際は、画像内の同じ身体位置にアンカーを合わせます。`scaleX/Y` は肩中心を固定した倍率、`offsetX/Y` は肩幅・胴体長を単位とする身体軸方向の移動量、`rotationOffset` はラジアンです。描画処理に左右反転を追加しないでください。動画・服・骨格は共通の親要素で一度だけ反転します。
